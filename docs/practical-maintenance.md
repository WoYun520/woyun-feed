# v0.27 精选材料维护

文中的 `practical-material-review-20261003.json` 不在当前仓库里。下面的复核步骤仍然可用。公开栏和定时见 [架构](architecture.md)。

面向用户，主要显示：能做什么、怎么开始、适用设备、限制、已知费用、官方原链接，以及最近一次说明核对日期。无法确认的费用仍写未知。

维护不是实测。2026-10-03由AI阅读8条已有材料的官方文档，未安装软件、未实际运行，未把核对结果当用户验收。结构化来源记录曾记在 `practical-material-review-20261003.json`，这份文件不在当前仓库里。本轮补充系统条件、翻译语言边界、LocalSend设备范围，并把Flameshot许可精确为GPLv3或后续版本。

每30天显示“说明待复核”，这是维护提醒，不表示软件失效。到期不会删除材料、自动调用AI或生成新的收费结论。网站的定时资讯更新不负责核对这些精选说明；维护者需要重新阅读官网，确认后随版本发布。

维护步骤：

1. 运行 `node frontend/check-materials.mjs`，查看各条核对日期与是否到期（只列提醒，不抓官网）。
2. 阅读材料官方功能、下载兼容条件、费用与许可说明，记录可支持的内容；不明之处保留未知。
3. 修改当前材料说明前，把此前准确发布的公开描述保留到`practicalHistory.js`。不纳入用户私人笔记。
4. 更新当前说明与实际阅读日期、官方依据链接，再运行相关检查与公开目录审计。

收藏和主题仍保留原始快照。曾发布的准确旧版说明可被识别，并显示“保存的旧版说明”或历史日期；修改过的备份、同名同编号但内容不符的条目不会因此获得核对标记。原始简介和来源不自动升级，用户可打开官网查看新条件。

未实现后台自动重查官网、自动纠错、跨设备同步或全部软件实测。维护提示不能保证最新版本或全部设备兼容。
