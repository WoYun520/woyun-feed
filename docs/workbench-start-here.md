# 我的信息流：从好材料，到自己的下一步

这里帮你发现材料、自己挑选，再把原文出处、个人判断和下一步整理成一份可以交给 AI 的材料。

## 第一次用，先做一件小事

比如：找一个视频转笔记工具，试完写篇教程。

1. **找材料。** 在“今日”或“实用教程”点标题看原文，觉得有用就收藏。已有站外链接，也能点“添加材料”。
2. **挑采集结果。** Dot 或 feedgrab 送来的材料在“待筛选”。可以搜关键词、选类型、设收藏门槛，再点“应用筛选”。勾选后点“选入精选”，不想留的点“暂不收录”。收藏数未知的材料不满足门槛；改变筛选会清空勾选。
3. **补自己的判断。** 到“我的精选”或“收藏与跟进”点“放进主题”。主题起一个自己看得懂的名字。点“编辑想法与进度”，写一句为什么值得试、还缺什么、接下来做什么。实际做完再填结果。
4. **带给 AI。** 在主题点“带走这份材料”，检查后点“复制给 AI”，到常用 AI 里粘贴并发送。也可导出 Markdown 放进个人知识库。

自己收藏的材料可直接放进主题，不需要先导入采集文件。收藏中还能“补摘录与想法”；想继续查清的问题可用“继续查一查”。

## 采集怎么接进来

已有素材文件时，在“待筛选”导入 Dot 或 feedgrab 的 JSON。自动接收需要先连接私人接收箱，并让采集工具完成实际投递。单靠打开网站不会自动抓到 X 素材。收到的材料都先待筛选，精选由你决定。

## 记住这几件事

互动数只是线索，选入精选不等于实测，也不会自动公开。添加链接不会自动读完原文；复制不会自动发送。原材料与自己的想法分开保留，没做过的事不要填成结果。

收藏、主题和筛选结果只存在当前浏览器。换设备或清理数据前，到“主题工作台”使用“备份与恢复”。不要放入密码、密钥或私人材料。
