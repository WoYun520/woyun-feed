关于这个预览

把各处的公开信息放在一起，先读原文，留下有用的材料，再带给自己的 AI。

怎样使用

  1. 首页点“管理来源”，勾选想看的板块，把常看的置顶，再保存。先点“看摘录”读来源摘要；点标题读原文，点书签收藏。站外链接也可手动添加。
  2. 到收藏里补摘录与想法，再放进一个主题；也可从首页精选两次点击创建试用或选题卡片。
  3. 主题里看起步清单、补自己的想法，点“带走这份材料”复制或导出给常用 AI。预填目标与清单是本站建议，不是已完成的工作。

网络慢时也能继续读

成功打开后，浏览器会单独暂存已读取的公开内容。下次打开先显示缓存，再检查网站更新；页面会标明当前显示资料的整理时间，原站获取时间仍见各来源。读取超过10秒会停止等待，可点“重新连接”。失败时保留旧内容与收藏。

缓存不是最新内容的保证，也不会触发云端重新采集。首次打开、清理浏览器后或缓存不可用时仍需联网；这不是完整离线网站，网页本身仍需能够载入。缓存与收藏、摘录、主题分开，容量不足时优先保护自己的材料。浏览器禁用存储时仍可阅读，但不能保证下次保留。

怎样按需要找材料

首页可搜标题、简介、仓库名和已有的中文用途；也可点写作与笔记、图片与视频等用途按钮，再加关键词。多个词用空格隔开，需同时匹配。字幕、截图、整理文件支持少量中英文同义词。搜索遵守当前来源分类、隐藏来源和只看新增设置，未接通来源没有材料就不会出结果。

查找只在当前浏览器中进行，不发送给 AI、不读取网页全文；用途按钮按关键词分组，不能代表功能已验证。搜索与用途只在当前页面暂留，刷新后清空；搜索结果可收藏或直接放进主题。

实用材料从哪里来

另补8条字幕、截图与文件整理的工具或官方操作教程。AI阅读官方说明后整理用途、开始步骤、平台限制和已知费用，中文标题由本站整理，未安装或实测，也不代表用户验收。每条保留官方原链接；费用不明就说明未知。

这些参考材料随网站版本发布，不参加云端定时抓取，不把说明阅读时间当成软件发布时间，也不混入最近一轮新增。收藏、主题、备份与导出会保留完整整理及原链接。搜索时工具、教程和GitHub 项目优先，同类保持原顺序；其余内容仍可阅读。隐藏来源和分类条件同样有效。

推特板块从哪里来

“推特”分类展示SoPilot的综合、AI、自媒体、财经四份公开24小时上涨榜，来源按其曝光榜采集，每榜最多前2页、100条；首页合并同帖，具体操作线索优先，每次先显示5条，点“再看”继续。实际数量取决于来源，分类和热度不等于本站推荐或核验。

同帖合并为一份材料，各榜保留自己的原排名和热度。点标题到X读原帖；本站只保留第三方摘录、作者与可用时间，没有接通X官方接口，也没有读取完整原帖。后续页读取失败时保留该来源上次完整内容，不把半份结果当成成功更新。

教程怎样开始

教程卡片先显示具体用途和适合谁，点“开始前看一下”查看工具条件、第一步和已知费用。没读清的材料显示未知，不从开源或旧活动推断当前免费。

这些提示是本站另行阅读后整理的笔记，作者案例是否实际跑过见独立记录；原始订阅或推文摘录仍保留自己的范围与日期。查看依据可以看到原标题、原链接和整理阅读日期。按用途、人群或准备条件搜索；放进主题后，带走材料会分开列出当前补充说明与收藏时的来源摘录，不改写你的旧收藏。

实用教程：先选人，再选内容

在“实用教程”按想做的事或博主查看材料，不要求标题含AI，也不按点赞数决定实用性。“博主库”先收录13位候选，默认启用8位；可启用、暂停并写自己的关注理由。作者入库不等于所有帖子都值得推荐，暂停不删除收藏和主题，也不停止公共来源更新。

目前包含8份AI阅读作者说明后的中文整理，以及按明确操作、实例和资源规则选出的推文方法线索。每条给原链接与读取范围；新增阮一峰视频处理教程和 Markmap 作者的入门说明，作者主页按真实博客或 GitHub 入口展示，未编造 X 账号。FFmpeg 另附合成视频单帧截图的实际记录；其余阅读说明不等于安装实测，摘录不等于读过完整原帖。4份指定作者公开榜单各取近7日曝光前10条，会漏掉低曝光、未收录动态、线程后续与图片内容。没有足够材料时少展示，不用新闻和观点凑数。

作者选择和关注理由只保存在当前浏览器，本机版与公开版分开，不包含在资料备份中。这些作者说明样本随网站版本维护；公开榜单参加既有定时更新，不能据一次成功读取保证长期可用。

博客教程怎样补充

Viking和向阳乔木使用各自公开博客订阅，最近最多30篇，按作者原文时间展示，不要求上热榜。首页保留订阅文章；实用教程只挑有具体操作线索的材料。原文全文不公开，订阅提供正文时只临时用于规则初筛，材料只保存订阅摘要、原链接与时间，未实测。博主库分别显示博客和推文榜的状态。

断网、短超时和原站临时错误会在原更新期限内短暂再试一次，每轮额外请求有上限。拒绝访问、链接不存在、格式或身份不匹配不反复请求，失败保留旧资料。没有新增定时频率或付费数据服务。

帖子附图怎样展示

精选和推特列表可显示来源提供的一张主帖静态附图。视频只显示封面，不播放；点击可放大，并打开原帖。来源没有提供或图片无法加载时仍可读文字、收藏和放进主题。

图片地址来自SoPilot公开数据，不代表本站已经读完原帖、看懂图片步骤或验证演示。只保留公开图片链接，不下载或镜像远程附件，不能保证所有设备都能加载。图片不改变精选标准，原帖地址不匹配时不借用图片。

精选优先：少而有用

首页先看精选，其他来源默认折叠；选定某个来源分类时可直接浏览相应板块。入选理由直接显示。推文需要已有安装命令、具体软件步骤或完整可复制示例，GitHub项目需要已有中文用途。观点和新闻可在原列表继续阅读，不够时不勉强凑数。自动初筛仍可能遗漏，未亲自实测的材料不会标成实测。

新教程候选

补入电脑玩物、雷蒙与番茄主理人的公开作者订阅。候选区按订阅里的操作线索初筛，展示用途线索、待确认的准备条件与原文入口；相同链接合并，锁定与测试文章先排除。原文日期与最近一次更新新收录分开，旧文章本轮读到不等于刚发布。可收藏或放进主题。

候选仅依据订阅摘录，不是全文核验或实测。更新失败保留旧材料，自动更新仍为原有每天09:00/21:00，不新增付费服务。为了给作者订阅留出请求余量，Hacker News每轮最多10项，实际条数按余量调整。

今日精选是什么

从最近保存的材料里，先挑最多3条用途清楚的工具与操作方法。每条说明用途、适合谁、准备条件与费用；长依据可以展开。点“我想试试”或“做成选题”，再点“保存并开始”，材料、名字和起步目标会一起带入卡片。已有收藏的理由和摘录也会保留。

日期是北京时间的整理日期，原发布时间或采集时间另列。来源更新或筛选条件改变后重新挑选；资料不足时少选。它是自动初筛，没有亲自试用，也不保证收益。不足时最多补2条固定官方说明，明确标为“非今日更新”，保留阅读日期；超过30天不再推荐。抽奖引流和只有模型性能的发布消息不进入精选。失败来源和仅有标题的内容仍留在原板块。

推特怎样去重与初筛

同一条X原帖即使出现在多个榜单，首页推特列表也只展示一次，并保留来源标签。同一明确GitHub项目或外部材料链接的多篇介绍可合在一组，展开仍能查看、收藏各自原帖。这不是AI对相似观点的判断，也不把多篇介绍当成已核验结论。

明确抽奖、邀请返佣、注册领奖等内容先折叠，可点“查看折叠的”恢复查看，搜索里也能展开。规则可能误筛和漏筛，有具体步骤的教程、收费工具介绍与经营复盘不会仅因收费或收入字样被折叠。原帖、收藏和主题不删除、不改写。

“更新详情”集中列出未更新来源的原因、上次成功与最近尝试时间。连续未更新次数从本版开始记录，不猜测过去的次数。失败仍保留旧材料；格式错误、拒绝访问和超时需要原站实际恢复，界面整理不代表这些问题已根治。

内容怎样更新

云端每天 09:00、21:00（北京时间）读取公开来源，不需要站长电脑开着。“查看更新”读取最近完成的内容，不会重新抓取原站。各板块显示实际获取时间，失败时保留上次内容。

小众软件、爱范儿和36氪使用各自的官方订阅，提供实用工具、科技产品与商业资讯；摘要由来源提供，本站未读取文章全文。没有摘要的条目只显示标题，不编造正文。

SoPilot 提供综合、AI、自媒体、财经四份 24 小时上涨榜，首页将相同原帖合并展示，保留来源标签；优先展示摘录里有操作、教程或材料链接的内容。点帖子打开 X 原链接；本站保存第三方榜单摘录，未核对原帖、作者身份或热度。作者、时间和热度会随收藏与主题保留。已移除未接通的X官方占位板块；SoPilot推文榜、作者材料和手动添加原帖链接继续保留。YouTube 展示指定频道新视频，没有观看视频或读取字幕；本站不保存网页全文，项目中文用途会注明整理依据和未实测状态。

收藏变了，主题怎样处理

新放进主题的材料会记住当时的收藏摘录与想法。后来收藏修改了，主题页和收藏页提示差异；点“查看变化”，逐项勾选更新，或明确保留主题内容。单独改过的主题和没有关联记录的旧主题不会默认勾选。原始来源简介与其他主题不会被覆盖。带走材料前会提醒，导出仍以主题里的内容为准。

工具说明怎样维护

精选材料显示官方说明核对日期，核对用途、设备条件、限制与已知费用，仍不代表安装实测或用户验收。每30天提醒待复核；到期不表示工具失效。维护者阅读官网后随网站版本更新，不自动生成新结论，也不改写你的旧收藏。保存的旧版说明会提示，原链接和原内容继续保留。

Dot 素材怎样导入

打开“待筛选”，点“一键导入 Dot 素材”，选择 Dot 交付的 JSON 文件。系统先检查格式和链接，再按同一条推文去重；已有信息流或收藏里的原帖不会重复导入。

逐条查看用途、原帖、热度查看时间和未知项，勾选后点“选入精选”。它们会出现在首页“我选的精选”，仍标为采集者整理、未实测；“暂不收录”的材料以后也能恢复。收藏数未知就显示未知，不用点赞或浏览量推算。

手动文件导入不上传。连接“Dot 自动投递”后，Dot 的公开素材先进入私有云端收件箱，保留30天；网站打开后自动同步、去重。投递密钥只能送来材料，独立接收码只能读取收件箱，双方都不能自动选精选或发布。接收码需在当前浏览器连接一次，不放进备份。筛选结果仍在当前浏览器，不自动公开发布。可导出精选 JSON；完整资料备份也包含待筛选、精选和已略过的记录。旧素材会保留当时的数字与时间，重新导入不会覆盖旧记录。

你的材料存在哪里

收藏、主题、摘录和偏好只存于当前浏览器，不上传给站长、不自动发送给 AI。不同浏览器和设备不会同步，清理浏览器数据会丢失。收藏、主题和摘录可在“收藏与跟进”里使用“备份与恢复”；首页显示和置顶设置只保存在此浏览器，不包含在资料备份里。隐藏来源不会删除收藏，也不会停止网站的定时读取。不要存入密码、密钥或私人原件。

本站没有登录、支付或访客追踪脚本；网站托管服务仍会接收正常的访问请求。打开原文后，适用原网站的规则。
